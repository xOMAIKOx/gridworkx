# GRIDWORKS Godot client foundation

This project establishes the Godot 4.x presentation boundary and the four accepted navigation layers: World Map, Player Portfolio Map, Site/Business View and Operational Detail View.

The client does not contain authoritative simulation mathematics. The future Rust GDExtension boundary consumes versioned command/state contracts from `packages/schemas` and `crates/gridworks-sim` under its own authorized work package.
